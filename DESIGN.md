# Brand & UI Design System: AgriPOS

## 1. Brand Identity
**Vision**: Modern, reliable, B2B SaaS for agricultural supply distribution.
**Mood**: Organic Technology, Professional, Clean, Trustworthy.

### Branding Elements
- **Logo**: Simple, geometric icon representing growth/agriculture, paired with a modern sans-serif typeface.
- **Color Palette (Earthy/Nature Inspired)**:
  - Primary (Nature): `emerald-700` / `earth-600`
  - Secondary (Tech): `teal-600`
  - Background: `earth-50` (Ivory/Off-white)
  - Surface: White
  - Text: `earth-900`, `earth-700`, `earth-600`
  - Semantic: `orange-600` (Debt/Low Stock/Warnings)

### Typography
- **Primary (UI)**: Inter (Sans-serif) - Versatile, legible.
- **Headings (Display)**: Outfit (Sans-serif) - Tech-forward, distinctive.

---

## 2. UI Moodboard & Philosophy
- **Approach**: Mobile-first, fast-paced POS operations, high whitespace.
- **Components**: Rounded corners (`rounded-xl`), soft shadows (`shadow-sm`), concise feedback.
- **Iconography**: Line icons (Lucide-react), consistent weight.
- **Interaction**: Clear hierarchy, prominent CTAs, instant feedback.

---

## 3. Component Style Guide
- **Buttons**: Rounded-md/lg. Primary: Solid color + high contrast text. Secondary: Outline or Ghost.
- **Cards**: White background, soft border, rounded-xl, light padding.
- **Inputs**: Clean edges, elevated background on focus (`bg-white` over `bg-earth-50`), consistent padding.
- **Dashboard**: Card-based, bento-grid patterns for KPIs, responsive charts.
- **Tables**: Clean rows, alternate row colors if necessary for readability, dense information display on mobile, spread on desktop.

---

## 4. Design Principles
1. **Minimize Clutter**: Focus on data-density without sacrificing readability.
2. **Context First**: Warnances and debt alerts should be unmissable but not alarming.
3. **Speed**: POS interface requires minimal path length to checkout.
4. **Professionalism**: Avoid playful or overly decorated UI.
